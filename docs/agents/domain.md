# Domain Docs

This repository uses the single-context layout.

## Before exploring

- Read `CONTEXT.md` at the repo root if it exists.
- Read ADRs under `docs/adr/` that touch the area being changed.
- If those files do not exist, proceed without creating them upfront; create them lazily when a domain decision is actually resolved.

## Vocabulary

Use the terminology defined in `CONTEXT.md` when it exists. If a needed concept is absent, record that as a domain-modeling gap instead of silently inventing competing names.

## ADR conflicts

If proposed work contradicts an existing ADR, surface the conflict explicitly rather than overriding it silently.
